# BuryatGo: учим бурятский язык 🇷🇺

Офлайн-приложение для Android в стиле Duolingo. В нём есть уроки, маскот Бато с магазином одежды, валюта «Буузы», серии, лиги, профиль, настройки звука и уведомлений, а также пейвол BuryatGo Super.

## Стек

| Слой | Технология |
|---|---|
| Оболочка | Android, Kotlin, AppCompat, WebView и WebViewAssetLoader (minSdk 26, targetSdk 34) |
| Интерфейс | HTML5 + CSS3 + чистый JavaScript (ES2017) без фреймворков и сторонних библиотек |
| Данные | `localStorage` с резервной копией и миграцией. Работает полностью офлайн |
| Звук | Web Audio API (синтез звуков и фоновой мелодии, файлы не нужны) |
| Озвучка | Android TextToSpeech через JS-мост (`AndroidBridge.speak`) |
| Уведомления | AlarmManager, BroadcastReceiver и NotificationCompat с перезапуском после перезагрузки |
| Вибрация | Vibrator / VibratorManager через мост |

Почему такой стек: он даёт плавные анимации на 60 fps даже на бюджетных Vivo, Poco и Redmi. APK весит около 2–3 МБ, приложение не требует интернета, а весь интерфейс можно проверить в обычном браузере.

## Сборка APK

### Вариант А: GitHub Actions (компьютер не нужен)
1. Создайте пустой репозиторий на github.com.
2. Загрузите в него всё содержимое папки `BuryatGo` (кнопка «Add file → Upload files», включая папку `.github`).
3. Откройте вкладку **Actions** и запустите workflow **Build BuryatGo APK** (он стартует и сам после загрузки).
4. Через 4–6 минут откройте завершённый запуск и скачайте артефакт **BuryatGo-debug-apk** (или **BuryatGo-release-apk**). Внутри лежит `app-debug.apk`.

### Вариант Б: Android Studio
1. Установите Android Studio (Koala или новее).
2. Выберите File → Open → папку `BuryatGo/android`.
3. Дождитесь синхронизации Gradle. Если Studio предложит создать Gradle Wrapper, согласитесь.
4. Выберите Build → Build App Bundle(s) / APK(s) → Build APK(s).
5. Готовый файл появится в `android/app/build/outputs/apk/debug/app-debug.apk`.

Из командной строки (нужны установленные Gradle 8.7+ и Android SDK): `cd android && gradle assembleDebug`.

## Установка на телефон

**Общее для всех:** скопируйте APK на телефон и откройте его в «Файлах». Разрешите установку из этого источника.

**Vivo (Funtouch OS / OriginOS):** Настройки → Безопасность → «Неизвестные источники» → вкл. Если появится «Безопасная установка» или проверка аккаунта Vivo, отключите её в Настройки → Безопасность → «Безопасная установка».

**Poco / Xiaomi / Redmi (MIUI / HyperOS):** при первом запуске разрешите установку для «Файлов». Если ругается «Защита приложений», нажмите «Всё равно установить». Чтобы напоминания приходили вовремя, откройте Настройки → Приложения → BuryatGo и включите **Автозапуск**, а в разделе **Контроль активности** выберите «Нет ограничений».

При первом включении напоминаний Android 13+ спросит разрешение на уведомления. Разрешите его.

## Важно про оплату

Экран подписки (499 ₽ в месяц, 5 600 ₽ в год) полностью работает внутри приложения: выбор тарифа, «оплата», открытие модулей, управление подпиской, отмена и восстановление. Но это **демо-оплата**, реальные деньги не списываются. Для настоящих платежей нужно подключить Google Play Billing (при публикации в Google Play) или RuStore Billing / ЮKassa (для RuStore). Точка интеграции находится в функции `purchase()` в `js/app.js`.

## Сборка под iOS

Проект не использует Expo, поэтому файла `app.json` в нём нет. Маскот и все предметы магазина рисуются встроенным SVG (`js/mascot.js`), так что путей к картинкам, зависящих от платформы, нет: одни и те же файлы работают на Android и iOS.

Для iOS веб-часть оборачивается в Capacitor. Настройки лежат в `capacitor.config.json` (`webDir` указывает на `android/app/src/main/assets/www`). Понадобится Mac с Xcode и Apple ID:

```bash
npm install
npx cap add ios
npx cap sync ios
npx cap open ios   # в Xcode: Signing & Capabilities → Team → Run
```

Вибрация и ежедневные напоминания на iOS работают через плагины `@capacitor/haptics` и `@capacitor/local-notifications`, приложение подключает их автоматически. Безопасные зоны (вырез, «чёлка») учтены через `env(safe-area-inset-*)`.

Дополнительно приложение можно установить как PWA: Safari → «Поделиться» → «На экран Домой». Для этого уже есть `manifest.webmanifest` и иконки в `www/img/`.

Как поставить без ограничения «7 дней»:
- **Старые iPhone (iOS 14.0 – 16.6.1, 16.7 RC, 17.0):** TrollStore → открыть `BuryatGo.ipa` → Install. Работает навсегда.
- **Новые iPhone:** AltStore (AltServer на Mac/PC) или SideStore с бесплатным Apple ID — подпись продлевается автоматически в фоне (AltStore — когда телефон и компьютер в одной Wi-Fi; SideStore — сам с телефона). Прогресс не теряется.
- **На год:** платный Apple Developer ($99/год) — открыть `ios/` на Mac: `brew install xcodegen && cd ios && xcodegen generate && open BuryatGo.xcodeproj`, выбрать команду в Signing и нажать Run.
- На iOS 16+ включите: Настройки → Конфиденциальность и безопасность → Режим разработчика.

iOS-обёртка (`ios/BuryatGo/*.swift`): WKWebView с тем же кодом игры, сохранение прогресса, вибрация (Taptic Engine), ежедневные напоминания, звук и озвучка, внешние ссылки открываются в Safari/Instagram.

## Версия 1.9 — Safari и аккаунты (логин + пароль)

### Игра в Safari
GitHub Actions (`.github/workflows/pages.yml`) публикует игру на GitHub Pages.
1. GitHub → Settings → Pages → Source: **GitHub Actions**.
2. После пуша ссылка появится в Actions → «Publish BuryatGo for Safari» (вида `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/`).
3. На iPhone откройте ссылку в Safari → «Поделиться» → **«На экран Домой»**. В игре есть подсказка: Настройки → «На экран Домой».

Игра работает и без интернета (service worker `sw.js`), а браузер просят не удалять сохранение (`navigator.storage.persist`).
Важно: Safari может стереть данные сайта, если его не открывать 7 дней, и стирает их при очистке истории. Иконка на экране «Домой» от этого правила освобождена, а аккаунт защищает прогресс полностью.

### Аккаунты и облачное сохранение (Firebase, бесплатный тариф Spark)
Прогресс каждого игрока хранится на сервере под его логином и паролем: переживает перезапуск браузера и телефона, очистку Safari и переезд на новый телефон.
1. https://console.firebase.google.com → «Создать проект» (Google Analytics можно выключить).
2. **Authentication** → «Начать» → Sign-in method → **Электронная почта/пароль** → Включить.
3. **Firestore Database** → «Создать базу данных» → режим production → регион, например `europe-west`.
4. Firestore → вкладка **Правила** → вставить и опубликовать:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```
5. Настройки проекта (⚙️) → Общие → «Добавить приложение» → Веб (`</>`). Скопировать `apiKey` и `projectId` в `www/js/cloud-config.js`.
6. Запушить: вход появится в Настройки → Аккаунт и на первом экране («У меня уже есть аккаунт»).

Как это работает:
- Логин: латиница, цифры, `.` `_` `-`, 3–20 символов. Пароль от 6 символов, хранится у Firebase в зашифрованном виде.
- При регистрации текущий прогресс уходит в аккаунт. При входе на другом телефоне прогресс загружается.
- Каждое изменение сохраняется в облако через 2–3 секунды, при сворачивании игры — сразу. Без интернета сохранение ждёт сети.
- При запуске подтягивается более свежий прогресс с другого устройства.
- «Выйти» отправляет прогресс в облако и очищает устройство для следующего игрока.
- Вход работает и в APK, и в iPhone-версии (тот же код).
